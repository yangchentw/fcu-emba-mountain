# 逢甲大學 EMBA 峰鷹登山協會官方網站設計規格

**狀態：** 已確認的設計方向，待使用者審閱後進入實作計畫。

## 1. 目標與範圍

建立逢甲大學 EMBA 峰鷹登山協會的繁體中文官方網站，協助逢甲 EMBA 師長、校友與在校生認識協會、查看活動社群、理解入會方式，並前往第三屆招生表單報名。

第一版為靜態網站，不建立後台、帳號、資料庫、站內表單或活動報名系統。活動公告與社群互動繼續由既有 Facebook 社團承接；入會由既有 Google 表單承接。

## 3. 資訊架構與路由

所有主選單項目都是獨立的靜態頁面，使用結尾斜線的永久網址，並由同一導覽列、頁尾與麵包屑（首頁除外）串連。

| 網址 | 導覽名稱 | 內容與主要行動 |

## 4. 視覺設計

視覺方向採「沉浸式影像敘事」。使用協會提供的山景照片，避免以可辨識人物為主角。Logo 的山林綠與日出金建立辨識度；版面採 Apple 產品頁般的大留白、短標題、聚焦主敘事與高品質攝影，但不模仿 Apple 的商標、文案或特有 UI。

### 色彩與字體

- 山林綠：`#496F3F`，主色、導覽互動與深色區塊。
- 日出金：`#E5B900`，主要按鈕、重點標示與小型強調。
- 墨綠黑：`#132017`，主文字與深色背景。
- 雲霧白：`#F3F5F1`，頁面底色。
- 內文優先使用系統中文字體堆疊：`-apple-system, BlinkMacSystemFont, "Noto Sans TC", sans-serif`；不讓字體下載延遲首屏。

Logo 採綠金版本，置於淺色導覽列；深色照片背景時使用白色或單色替代版本，避免在複雜照片上直接使用彩色 Logo。

### 影像原則

- 優先使用資料夾 `照片/` 中橫式大景作首頁首屏與區段背景；直式照片用於內頁雙欄或單張沉浸區塊。
- 發布前逐張檢查人物是否可辨識；未取得同意者不使用，或裁切、遮蔽至無法辨識。
- 每張影像提供具描述性的繁體中文替代文字；純裝飾影像使用空替代文字。
- 建置時輸出 AVIF 與 WebP 響應式尺寸，原始 JPEG 不直接作為首屏傳輸檔。

## 5. 首頁互動與各頁行為

首頁按下列順序構成，每段皆為實際 HTML 內容與普通連結，不將關鍵文字藏在 Canvas 或影片內：

1. 開場：遠景、協會名稱、標語「登上山，走向更遠。」與第三屆招生 CTA。
2. 緣起與使命：2014 至 2023 的故事、安全與保育承諾，連至 `/about/`。
3. 活動與社群：社團日、假日活動與 Facebook 社群入口，連至 `/activities/`。
4. 傳承：歷屆領導時間軸摘要，連至 `/legacy/`。

桌面版使用 CSS scroll-driven 或 Intersection Observer 驅動的 `opacity` 與 `transform` 淡入／縮放；不使用捲軸劫持、全頁滾輪換頁、長時間影片或需要 JavaScript 才能閱讀的效果。`prefers-reduced-motion: reduce` 時移除動畫和固定背景。手機版使用一般垂直內容流，不保留容易造成暈眩或卡頓的固定視差。

導覽列在桌面固定於上方，行動版為可操作、可關閉的選單。所有鍵盤焦點可見，跳至主要內容連結放在頁面最前。

## 6. 技術與 Cloudflare 部署

- 使用 Astro 靜態站點生成，產出純 HTML、CSS 與最少量 JavaScript；不需要 Cloudflare Workers、KV、D1 或後台。
- 使用 Cloudflare Pages，從 Git 儲存庫持續部署；建置命令為 `npm run build`，輸出資料夾為 `dist`。
- 使用 Cloudflare Pages 的預覽部署檢查每次變更，正式網域啟用 HTTPS 與自訂網域後，將 `www` 導向唯一正式主網域。
- 專案提供 `404.html`、`_headers` 安全標頭與長快取的不可變雜湊靜態資產；HTML 採短快取或由 Pages 預設處理，以利固定網站內容重新部署後更新。

## 7. SEO、分享與無障礙規格

- 每頁有唯一的 `<title>`、meta description、canonical URL、單一 `<h1>`、符合層級的標題與可索引的內文。
- 產生 `sitemap-index.xml`／`sitemap-0.xml`、`robots.txt`，並在部署後提交 Google Search Console。
- 每頁有 Open Graph、Twitter Card、`og:image`（1200×630），使用山景與 Logo 組合，不含可辨識人物。
- 首頁與協會資訊頁加入 `Organization` JSON-LD；活動頁加入 `CollectionPage` JSON-LD；外部連結不宣稱為協會自有網站。
- 遵守 WCAG 2.2 AA：文字與背景對比至少 4.5:1、鍵盤可操作、圖片替代文字、表單／連結可辨識、無只靠顏色傳達的資訊。
- Lighthouse 目標：效能、無障礙、最佳實務、SEO 四項皆至少 90；首頁行動網路 LCP 目標低於 2.5 秒。

## 8. 內容維護方式

雖不設後台，文字、歷屆名單、連結與更新日期集中為版本控制中的內容資料檔。照片置於受版本控制的資產資料夾。未來要更新招生連結、Facebook 或新一屆名單時，只調整資料檔與必要影像，重新部署即可。

活動即時資訊不在網站複製；活動頁清楚標明 Facebook 社群為最新公告來源，避免固定網頁內容過期。
