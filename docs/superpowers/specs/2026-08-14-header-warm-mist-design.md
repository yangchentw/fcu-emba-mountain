# Header 暖霧岩灰設計

## 目標

降低 header 純白的單調感，並讓導覽區與峰鷹 logo 的綠、黃識別色更協調。

## 視覺規格

- Header 背景使用暖霧岩灰 `#F4F1E8`。
- Header 底部使用 2px 峰鷹綠 `#496F3F` 細線。
- 品牌與導覽文字維持既有深墨綠，確保對比與可讀性。
- Header 的 sticky 行為、版面結構與手機版呈現維持不變。

## 驗證

- 建置後 CSS 包含 `#f4f1e8` 與 2px `#496f3f` header 底線。
- `npm run build` 與 `npm run test` 通過。
