# 首頁山語短詩設計

## 目標

以具山林詩意的短詩取代首頁主視覺的既有主標，讓首屏直接傳達協會的氣質。

## 版面與文字

短詩置於首頁 hero 中、取代既有的「登上山，走向更遠。」`h1`，使用語義化 `h1` 與三行保留換行：

> 山的美，雲知道  
> 雲的媚，風明瞭  
> 風的勁，山頂上的您知曉

文字採白色、置中對齊、寬度限制與較寬鬆行距，與山景背景維持足夠對比；手機版降低字級並維持每行完整閱讀。不額外保留重複的短詩區塊。

## 字型策略

- 詩句專用 `Noto Serif TC`，使用 500 或 600 字重，呈現沉穩的人文與山林感。
- 一般內文與導覽維持現有系統無襯線字體，避免全站載入後的閱讀節奏改變。
- 以 Google Fonts CSS 載入 `Noto Serif TC`，並設定 `serif` fallback；字型載入失敗時仍可正常顯示繁體中文。
- 僅請求實際使用的字重，避免不必要的字型下載。

## 可近用性與效能

- 不加入自動播放、逐字動畫或必須依賴 JavaScript 的效果。
- 不以圖片呈現文字，讓搜尋引擎、螢幕閱讀器與複製操作都能取得原文。
- 保持良好文字對比，並延續現有 reduced-motion 設定。

## 驗證

- 建置後的首頁 HTML 必須包含三行詩句與 hero 中的 `h1`。
- CSS 必須包含詩句專用 `Noto Serif TC` font-family。
- `npm run build` 與 `npm run test` 必須通過。
