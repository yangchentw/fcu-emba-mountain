# 組織與傳承：歷屆卡片色彩設計

## 目標

讓創會、第一屆、第二屆與第三屆在視覺上容易辨識，同時維持協會山林風格與姓名、職稱的閱讀清晰度。

## 設計

四張卡片沿用既有圓角、間距與排版，只依出現順序套用固定的山林色階背景：

1. 創會：暖岩砂色。
2. 第一屆：淡松綠。
3. 第二屆：霧藍灰。
4. 第三屆：峰頂金。

所有卡片的標題、職稱與姓名統一使用既有深墨綠 `#132017`，不以白字或各卡不同的字色呈現。每個背景色須與此文字色維持足夠對比；原有白色卡片樣式僅作為無色彩卡片的通用基底。

## 實作邊界

- 僅修改組織與傳承頁的四張歷屆卡片與必要的共用樣式。
- 不變更歷屆資料、內容文字、導覽、圖片或其他頁面的卡片。
- 以語意化的屆別 class 指派顏色，避免依 DOM 順序選取，讓後續新增或調整資料時保持穩定。

## 驗證

- 自動測試確認四張卡片各有明確且不同的屆別 class，以及共用深墨綠文字色。
- 執行網站建置與全數測試。
- 在組織與傳承頁確認四張卡片依序可見、文字可閱讀，且沒有版面溢位。
